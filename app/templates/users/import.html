How it works
  1. Download the template below and fill in one row per person.
  2. Upload the completed file.
  3. Review the preview — every row is validated before anything is written to the database.
  4. Confirm the import. Rows with errors are never imported. A row whose email already exists updates that user's name/status/school — it never changes their role.
  5. Each new account gets a random password nobody is shown — share the password-set link from the results page with that person instead.
